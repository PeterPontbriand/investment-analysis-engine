Usage: root watchlist add-selection graham-number [OPTIONS] {name}
{tickers}...
Add one Graham Number entry per ticker to an existing watchlist.
Arguments
* name <str> Watchlist name. [required]
* tickers <str> Tickers to add this selection for. [required]
Options
--as-of <str> Point-in-time boundary as YYYY-MM-DD or
timezone-aware ISO-8601 timestamp
--no-cache Bypass resolved-input cache reads and
writes
--eps -e <float> Explicit EPS override
--bvps <float> Explicit book value per common share
override (Number only)
--current-price -p <float> Optional explicit current-price override
--json Emit the updated watchlist document.
--help Show this message and exit.
