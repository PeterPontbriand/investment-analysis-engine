# Specimen Strategy Guide

The specimen is a trivial strategy that exists only for the conformance tests. It is not an investment method and
no command of the installed program offers it.

## What it does

It multiplies one input value by a configured multiplier. The formula is not part of the project's
[Financial Math](../../docs/user/FINANCE_MATH.md#eps-basis), and a user-supplied [override](../../docs/user/GLOSSARY.md#override)
of the input value is the only input it takes.

## Watchlist options

The specimen reads only the shared watchlist flags, the point-in-time boundary and the cache switch.
